A new box

Make this box yours.

It has no account and no default password. Whoever can read the code on the box itself becomes its administrator.

  1. The code from the box

    Eight digits. Run ex4-claim over ssh to read them (the box also offers them to its front screen).

  2. A name for the box

    Lower-case letters, digits and dashes. You will reach it as ex4.local.

  3. The administrator

    Twelve characters or more. Only a scrambled form of it is sent now, and only that is stored: the box keeps no password it could give away.

                Address

                A change is tried for 90 seconds. Unless this page reaches the box again and you keep it, the old settings come back by themselves: a mistyped address cannot lock you out.

                Certificate

                This box makes its own certificate, so a browser warns the first time. Compare the fingerprint it shows you with the one here; they must match. A new name wants a new certificate.

                Power

                Support bundle

                Logs to attach to a bug report, with addresses and serial numbers masked. It is made on the box and saved by your browser; it goes nowhere else.

                About

                Updates

                This box never looks for updates on its own and never calls anywhere by itself. Over ssh, “ex4-update check” asks the release address once; only a release signed with a key this box holds, for this board, newer than what runs and not past its expiry date, is ever accepted. Nothing is installed from here: a checked release is staged in memory and gone at the next start.
